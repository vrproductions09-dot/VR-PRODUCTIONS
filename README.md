# VR Productions — Landing Page

Premium event planning & production company website for Tricity (Chandigarh, Mohali, Panchkula).

## Features
- Fully self-contained single HTML file (no external image dependencies)
- SEO optimized with schema markup, meta tags, Open Graph
- Mobile-first responsive design
- Luxury, cinematic aesthetic with smooth animations
- WhatsApp integration for direct enquiries
- Google Maps embed
- Lightbox gallery, animated counters, FAQ accordion, review slider

## Deployment

### Netlify (recommended — free)
1. Go to [netlify.com](https://netlify.com) and sign up
2. Drag and drop the project folder into Netlify dashboard
3. Your site is live instantly!

### GitHub + Netlify
1. Create a GitHub repo and push all files
2. Connect repo to Netlify → auto-deploys on every push

### Google Search Console
1. Go to [search.google.com/search-console](https://search.google.com/search-console)
2. Add property → enter your domain
3. Verify via HTML meta tag (add to index.html head)
4. Submit sitemap: `https://yoursite.netlify.app/sitemap.xml`
